# 小智桌面机器人（STM32F407）

这是一个基于 启明欣欣STM32F407ZGT6 v6.1开发板 的四足桌面机器人固件工程。机器人通过 USART6 接收语音模块下发的单字节指令，使用四路舵机完成起立、坐下、前进、后退和摇摆等动作，并在 128x64 OLED 上播放动态表情。收到“坐下”指令后，还会读取 DHT11，显示 8 秒温湿度，语音模块采用su-03TI，在 https://www.smartpi.cn/ 中配置。

## 功能

- 21 组、868 帧小智动态表情循环播放，帧间隔 80 ms。
- 四条舵腿控制，支持起立、坐下、前进、后退、摇摆和趴下。
- USART6 中断接收动作编号，通信参数为 9600 bps、8 数据位、无校验、1 停止位。
- SSD1306/SSD1315 OLED 显示，自动探测 I2C 地址 `0x3C` 和 `0x3D`。
- DHT11 温湿度采集，读取失败时显示 `READ ERR`。
- 三路照明控制。

## 硬件连接

| 模块 | STM32 引脚 | 说明 |
| --- | --- | --- |
| 左前舵机 | PD12 / TIM4_CH1 | PWM 控制 |
| 右后舵机 | PD13 / TIM4_CH2 | PWM 控制 |
| 左后舵机 | PD14 / TIM4_CH3 | PWM 控制 |
| 右前舵机 | PD15 / TIM4_CH4 | PWM 控制 |
| 语音模块 TX | PC7 / USART6_RX | 接收语音指令 |
| 语音模块 RX | PC6 / USART6_TX | 预留发送 |
| OLED SDA | PG3 | 软件 I2C |
| OLED SCL | PG4 | 软件 I2C |
| DHT11 DATA | PG5 | 单总线 |
| 照明 | PG9、PE3、PE4 | 低电平点亮 |

舵机 PWM 周期为 20 ms，比较值范围为 50 至 250。舵机电源应与主控共地，可使用独立稳压电源，避免四路舵机同时动作时拉低 MCU 供电。

## 串口指令

语音模块每次发送一个字节，当前固件支持以下编号：

| 指令值 | 命令词 | 动作 |
| --- | --- | --- |
| `0x01` | 起立 | 四条舵腿回到站立姿态 |
| `0x02` | 坐下 | 前腿保持站立，后腿收至 0 度；随后显示温湿度 8 秒 |
| `0x03` | 开灯 | 打开三路照明 |
| `0x04` | 前进 | 执行一组前进迈步动作 |
| `0x05` | 关灯 | 关闭三路照明 |
| `0x06` | 后退 | 执行一组后退迈步动作 |
| `0x07` | 扭屁股 | 身体前后摇摆两次 |
| `0x08` | 叫 | 切换为惊讶表情 |
| `0x09` | 滚 | 当前固件调用收腿动作，与趴下共用 `Action_Getdowm()` |
| `0x0A` | 趴下 | 四条舵腿收至 0 度 |

指令定义同时保存在 [`SENSOR/src/语音指令.txt`](SENSOR/src/语音指令.txt)。

## 程序流程

程序启动后依次初始化照明、TIM4 舵机 PWM、OLED、DHT11 和 USART6。主循环持续刷新表情帧；一组表情播放结束后自动切换到下一组，播放完 21 组后回到 `neutral`。

USART6 中断将收到的最后一个字节保存到 `Usart6_Recv_data`。主循环读取该值，清零后执行对应动作。串口协议没有帧头、校验和队列，因此适合当前的逐条短指令场景，不适合连续高速通信。

## 目录结构

```text
.
├─ CMSIS/           Cortex-M4 内核与启动文件
├─ DEVICE_LIB/      STM32F4 标准外设库
├─ HARDWARE/        照明、串口和表情帧数据
├─ SENSOR/          舵机、OLED、DHT11 驱动
├─ SYSTEM/          系统时钟、延时和中断配置
└─ USER/            main.c 与 Keil 工程
```

`HARDWARE/src/LED.c` 包含全部 868 帧单色表情数据，因此文件体积约为 5.6 MB。

## 编译与烧录

1. 安装 Keil MDK，并确保已安装 STM32F4 器件支持包。
2. 打开 `USER/pro.uvprojx`。
3. 选择目标 `Target 1`，器件型号为 `STM32F407VGTx`。
4. 编译工程，通过 ST-Link 或工程当前配置的调试器下载程序。

工程使用 STM32F4 标准外设库，不依赖 HAL、CubeMX 或操作系统。编译输出默认生成在 `USER/Objects`。
